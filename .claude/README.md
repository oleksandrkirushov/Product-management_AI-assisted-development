# Архітектура Claude Code: skills та agents

```
.claude/
├── README.md                 # цей файл
├── agents/                   # субагенти (один .md файл = один агент)
│   └── <agent-name>.md
├── skills/                   # скіли (одна папка = один скіл)
│   └── <skill-name>/
│       ├── SKILL.md          # обов'язковий: frontmatter + інструкції
│       ├── references/       # опційно: довідкові матеріали, які скіл читає за потреби
│       ├── scripts/          # опційно: скрипти, які скіл запускає
│       └── assets/           # опційно: шаблони файлів (наприклад, заготовки компонентів)
└── templates/                # заготовки для створення нових скілів/агентів
    ├── agent.md              #   (Claude Code їх НЕ завантажує — лише для копіювання)
    └── skill/
        └── SKILL.md
```

## Skills vs Agents

| | Skill | Agent (субагент) |
|---|---|---|
| Що це | Пакет інструкцій/знань для конкретного типу задачі | Окремий виконавець зі своїм контекстом, моделлю та набором інструментів |
| Де працює | У поточній розмові (додає інструкції в контекст) | В ізольованому контексті, повертає лише результат |
| Коли використовувати | «Як робити X у цьому проєкті» — конвенції, кроки, шаблони | Самостійна багатокрокова задача: рев'ю, тести, аудит, дослідження |
| Виклик | Автоматично за `description` або `/skill-name` | Автоматично за `description` або «використай агента X» |

## Правила іменування

- Імена — `kebab-case`, лише латиниця.
- Папка скіла = поле `name` у `SKILL.md`; ім'я файлу агента = поле `name` у frontmatter.
- Скіли групуємо префіксами (вкладені категорії Claude Code не підтримує):
  - `angular-*` — генерація коду Angular (компоненти, сервіси, роутинг, форми)
  - `dotnet-*` — генерація коду бекенду на .NET (Clean Architecture, EF Core, API)
  - `state-*` — керування станом (signals, NgRx тощо)
  - `test-*` — юніт та e2e тести
  - `style-*` — стилі, UI-кіт, доступність
  - `workflow-*` — процеси: коміти, релізи, PR
- `description` — найважливіше поле: саме за ним Claude вирішує, коли підключати скіл/агента. Пишіть, **що** він робить і **коли** його використовувати.

## Як додати новий скіл

```bash
cp -r .claude/templates/skill .claude/skills/angular-component
# відредагувати name/description та інструкції в SKILL.md
```

## Як додати нового агента

```bash
cp .claude/templates/agent.md .claude/agents/angular-reviewer.md
# відредагувати name/description/tools/model та системний промпт
```

Перевірити, що агент підхопився, можна командою `/agents` у Claude Code.
