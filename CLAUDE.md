## Claude Code
- Скіли: [.claude/skills/](.claude/skills/)
  - `angular-best-practices` — правила Angular-коду
  - `test-karma-jasmine` — юніт-тести на Karma + Jasmine
  - `dotnet-clean-architecture` — конвенції Clean Architecture бекенду (`BE/`)
- Агенти: [.claude/agents/](.claude/agents/)
  - `angular-developer` — реалізація фіч у фронтенді (`FE/`)
  - `angular-reviewer` — рев'ю змін у `FE/` за тим самим скілом (код не змінює)
  - `angular-test-writer` — покриття коду у `FE/` юніт-тестами на Karma + Jasmine (змінює лише `*.spec.ts`)
  - `dotnet-developer` — реалізація фіч у бекенді (`BE/`)
  - `dotnet-reviewer` — рев'ю змін у `BE/` за скілом `dotnet-clean-architecture` (код не змінює)
- Типовий цикл FE (виконує головна сесія, субагенти один одного не викликають):
  1. `angular-developer` реалізує задачу.
  2. `angular-test-writer` доповнює тести для реалізованого коду.
  3. `angular-reviewer` перевіряє результат і повертає вердикт (✅ / ⚠️ / ❌).
  4. Якщо вердикт ⚠️ або ❌ (є 🔴/🟡 зауваження) — зауваження передаються назад `angular-developer` на виправлення
     (а зауваження щодо тестів — `angular-test-writer`), після чого знову `angular-reviewer`. Цикл повторюється,
     доки вердикт не стане ✅ (орієнтовно до 3 ітерацій; якщо проблема не усувається — зупинись і опиши її
     користувачу, а не намагайся нескінченно).
  5. Коли вердикт ✅ — результат (список змін, звіт рев'ю) показується користувачу. Коміт робиться лише після
     явного підтвердження користувача, автоматично в циклі не комітиться.
- Типовий цикл BE (виконує головна сесія, субагенти один одного не викликають):
  1. `dotnet-developer` реалізує задачу (разом з тестами).
  2. `dotnet-reviewer` перевіряє результат і повертає вердикт (✅ / ⚠️ / ❌).
  3. Якщо вердикт ⚠️ або ❌ (є 🔴/🟡 зауваження) — зауваження передаються назад `dotnet-developer` на виправлення,
     після чого знову `dotnet-reviewer`. Цикл повторюється, доки вердикт не стане ✅ (орієнтовно до 3 ітерацій;
     якщо проблема не усувається — зупинись і опиши її користувачу, а не намагайся нескінченно).
  4. Коли вердикт ✅ — результат (список змін, звіт рев'ю) показується користувачу. Коміт робиться лише після
     явного підтвердження користувача, автоматично в циклі не комітиться.
